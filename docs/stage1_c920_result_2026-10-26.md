
3. `v4l-utils`導入済みの環境で各indexを調べる。

実行前に `ros2 node list` でRobot nodeが見えないことを確認する。
模擬service名は `/care_patrol_test/set_paused`、guardの確認topicは
テスト専用名を使用する。模擬serviceは停止観測をpublishしない設定とし、
受理後の `request_accepted_unconfirmed` / `UNCONFIRMED` を正常結果として扱う。
実Robotのservice名を指定してはならない。

Terminal Aで停止観測を出さない模擬serviceを起動する。これは要求回数をログへ
出すだけで、Robot、`/stop`、`/cmd_vel`には接続・publishしない。

```bash
python - <<'PY'
import rclpy
from rclpy.node import Node
from std_srvs.srv import SetBool

class Stage1Mock(Node):
    def __init__(self):
        super().__init__('stage1_mock_pause_service')
        self.count = 0
        self.create_service(
            SetBool, '/care_patrol_test/set_paused', self.handle
        )

    def handle(self, request, response):
        self.count += 1
        self.get_logger().warning(
            f'mock request #{self.count}: data={request.data}; '
            'no physical stop was requested or confirmed'
        )
        response.success = bool(request.data)
        response.message = 'accepted by Stage 1 mock; physical stop unconfirmed'
        return response

rclpy.init()
node = Stage1Mock()
try:
    rclpy.spin(node)
finally:
    node.destroy_node()
    rclpy.shutdown()
PY
```
